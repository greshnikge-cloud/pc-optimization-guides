Глобально CS2 Valorant Как применить
1

Глобальные настройки (для всех игр)

Управление параметрами 3D → Глобальные
Режим управления электропитанием → Предпочтителен режим максимальной производительности
Вертикальный синхроимпульс → Выкл
Максимальное количество заранее подготовленных кадров → 1
Фильтрация текстур — Качество → Высокая производительность
Фильтрация текстур — Анизотропная оптимизация → Вкл
Фильтрация текстур — Негативное отклонение УД → Разрешить
Тройная буферизация → Выкл
Сглаживание — Режим → Управляется приложением
Сглаживание — Параметры → Управляется приложением
Потоковая оптимизация → Авто
Низкая задержка → Ультра (если есть)
OpenGL GDI-совместимость → Авто
2

Отдельный профиль под CS2

Программные настройки → Добавить → cs2.exe → те же значения + можно жёстче:

CS2 профиль
Режим управления электропитанием → Максимальная производительность
Вертикальный синхроимпульс → Выкл
Макс. заранее подготовленных кадров → 1
Низкая задержка → Ультра
Фильтрация текстур — Качество → Высокая производительность
3

Профиль под Valorant

VALORANT.exe
Режим управления электропитанием → Максимальная производительность
Вертикальный синхроимпульс → Выкл
Макс. заранее подготовленных кадров → 1
Низкая задержка → Ультра
Фильтрация текстур — Качество → Высокая производительность
4

Как применить

1. ПКМ по рабочему столу → Панель управления NVIDIA
2. Управление параметрами 3D
3. Глобальные параметры — выставь список выше
4. Программные настройки — добавь cs2.exe / VALORANT.exe и повтори
5. Применить → готово
