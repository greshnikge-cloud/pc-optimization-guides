1

Основной гайд по оптимизации Windows

  • 1
    Схема электропитания

    Панель управления → Электропитание → Высокая производительность. Или создай свою схему и поставь минимум 100% на процессор.

  • 2
    Визуальные эффекты

    Этот компьютер → Свойства → Дополнительные параметры системы → Быстродействие → Параметры → Обеспечить наилучшее быстродействие.

  • 3
    Автозагрузка

    Диспетчер задач → Автозагрузка. Отключи всё ненужное (Discord, Steam, браузеры можно оставить).

  • 4
    Службы Windows

    Win + R → services.msc. Отключи: SysMain, Windows Search, Fax, Remote Registry (если не пользуешься).

  • 5
    Файл подкачки

    Дополнительные параметры системы → Быстродействие → Параметры → Дополнительно → Виртуальная память. Поставь фиксированный размер (1.5–2× ОЗУ).

  • 6
    Игровой режим и Game Bar

    Параметры → Игры. Включи «Игровой режим», отключи Game Bar и записи, если не нужны.

Настройки NVIDIA / AMD

NVIDIA Control Panel → Управление параметрами 3D
Рекомендуемые значения 
Режим управления электропитанием → Предпочтителен режим максимальной производительности
Вертикальный синхроимпульс → Выкл
Тройная буферизация → Выкл
Максимальное количество заранее подготовленных кадров → 1
Фильтрация текстур — Качество → Высокая производительность
Анизотропная фильтрация → Выкл (или управляется приложением)
Сглаживание — Режим → Управляется приложением
CUDA — Графические процессоры → Все
AMD Software

Gaming → Graphics → Radeon Anti-Lag = Enabled
Radeon Chill = Off
Radeon Boost = Off (или On для слабых ПК)
Texture Filtering Quality = Performance

Дополнительно для CS2

Запусти CS2 с параметрами запуска:

Параметры запуска Steam 
-novid -high -threads 8 +fps_max 0 -nojoy

В игре: выключи VSync, поставь Multisampling Anti-Aliasing = None или 2x, Shader Detail = Low/Medium, Effect Detail = Low.

Быстрые советы

🧹

Очистка

Temp-файлы, %temp%, Disk Cleanup, CCleaner (осторожно с реестром)

📡

Сеть

Ethernet лучше Wi-Fi. Отключи фоновые обновления Windows во время игры

🖥️

Драйверы

Всегда свежие драйверы GPU + чистая установка через DDU при смене

⚡

Фон

Закрой браузер, Discord overlay, NVIDIA Broadcast если не нужны
