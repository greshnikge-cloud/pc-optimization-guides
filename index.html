Общий гайд Windows

  • 1
    Схема электропитания

    Высокая производительность. Минимум процессора = 100%.

  • 2
    Визуальные эффекты

    Этот компьютер → Свойства → Дополнительные параметры → Быстродействие → Обеспечить наилучшее быстродействие.

  • 3
    Автозагрузка

    Диспетчер задач → Автозагрузка. Отключи всё ненужное.

  • 4
    Файл подкачки

    Фиксированный размер 1.5–2× ОЗУ.

  • 5
    Игровой режим

    Вкл. Game Bar и записи — выкл.
