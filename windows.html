Ускорение Windows
Очистка + производительность

Пошаговый гайд: система станет быстрее, меньше фоновых процессов и тормозов

Очистка Автозагрузка Службы Питание Приватность
1

Очистка системы

  • 1
    Временные файлы

    Win + R → %temp% → удали всё. Потом temp и Prefetch.

  • 2
    Очистка диска

    Этот компьютер → ПКМ по диску C → Свойства → Очистка диска → Очистить системные файлы.

  • 3
    Хранилище

    Параметры → Система → Память устройства → Временные файлы + Корзина.

2

Автозагрузка

Диспетчер задач → Автозагрузка. Отключи всё, кроме антивируса, драйверов и действительно нужных программ (Discord/Steam можно оставить).

3

Службы (осторожно)

Можно отключить (если не пользуешься)
SysMain (Superfetch)
Windows Search
Fax
Remote Registry
Xbox Services (если не играешь в Xbox)
Connected User Experiences and Telemetry

Win + R → services.msc → найди службу → Свойства → Тип запуска: Отключена.

4

Питание и быстродействие

  • 1
    Схема электропитания

    Высокая производительность. Минимум процессора = 100%.

  • 2
    Визуальные эффекты

    Этот компьютер → Свойства → Доп. параметры → Быстродействие → Обеспечить наилучшее быстродействие.

  • 3
    Файл подкачки

    Фиксированный размер ≈ 1.5–2× объёма ОЗУ.

5

Приватность и телеметрия

Параметры → Конфиденциальность: отключи рекламный ID, диагностику «Полные», фоновые приложения, которые не нужны. Можно использовать O&O ShutUp10++ (бесплатно) для быстрой настройки.
